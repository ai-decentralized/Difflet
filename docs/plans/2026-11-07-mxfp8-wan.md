# MXFP8 on Wan 2.1-T2V-14B and Wan 2.2-T2V-A14B — Implementation Plan (phase C)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `--quant mxfp8` for Wan 2.1 (one DiT) and Wan 2.2-A14B (two experts) on the native
neuron backend, through the shared layer of phase A, with device evidence at the default
480x832x9 shape and the realistic 480x832x81 shape.

**Architecture:** the same mechanism as LTX-2 (phase B of
`docs/plans/2026-11-07-mxfp8-video-models.md`): a target table, the three base-class
attributes on the transformer application, `resolve_quant` in the pipeline application,
`prepare_quant` in the driver. Three things are Wan's own: the module names differ from the
checkpoint keys (`ffn.net_in` / `net_out` against `ffn.net.0.proj` / `net.2`), handled by
writing the targets in checkpoint-key spelling (the base already matches through
`checkpoint_key`); the hub DiTs are fp32, so the quantized checkpoint is written from the
repo's bf16 copy (`weights_bf16.ensure_bf16_copy`, made at `compile`), whose manifest joins
the source fingerprint; and Wan 2.2 holds two experts that share one block graph, so both get
the same spec and their own quantized directory.

**Tech Stack:** as phase B. Wan facts (survey 2026-11-07, `difflet/models/wan/modeling_wan.py`):
D=5120, 40 heads x 128, ffn 13824, text 4096 at 512 tokens, 40 blocks; `blocks.N.attn1/attn2.to_q/k/v`
Column (gather_output=False), `.to_out.0` Row (input_is_parallel), `ffn.net_in` Column, `ffn.net_out`
Row; per-block modulation is `scale_shift_table` (a Parameter); the attention calls `to_q/k/v`
directly (no fusion); SP, CP (gather_kv / ring / ulysses), CFG-parallel compose; tokens 4680 at
9 frames, 32,760 at 81 (CP2: 2340 / 16,380 — 2340 needs B7's padding); row-parallel K per rank
at tp4: `to_out` 1280, `net_out` 3456 (tp8: 1728, not a multiple of 128 — refused).

**Spec:** the roadmap entry C of the phase-A/B plan, the Wan survey, and this conversation's
decisions (quantize from the bf16 copy; same spec for both experts; realistic shape measured).

## Global Constraints

- Everything in the phase-A/B plan's Global Constraints (branch, push per commit, D43, no
  fusion, K % 128, byte-identical default command lines, 50 steps / seed 42 / LNC=2, CPU fp32
  reference last).
- Wan's target patterns are written in **checkpoint-key spelling** (`ffn.net.0.proj`,
  `ffn.net.2`); `quantize_module_(key_fn=checkpoint_key)` maps the module names.
- The quantized checkpoint's **source is the bf16 copy** when it exists
  (`resolve_component_dir(<root>/<expert>, bfloat16)`), so the writer copies bf16 non-targets
  byte for byte and the fp32 hub files are read once (by `ensure_bf16_copy`), never by the
  writer. A quantized directory records which it was built from (C2).
- Both experts of Wan 2.2 are quantized with one spec (one `QuantSpec`, two directories); a
  launch that quantizes one and not the other is impossible by construction.
- tp8 is refused for `--quant` (`net_out` per-rank K 1728): the writer names the layer, K and tp
  (phase A's A1 fix) and the driver turns it into the usual `refuse` (exit 2).

## Review Focus

1. A generate without a bf16 copy (compile never ran on this host) must resolve the quantized
   directory from the fp32 source and refuse with the `difflet compile` hint, never write — C5.
2. Wan 2.2 with `--quant` must count **both** experts' quantized bytes in the HBM check and
   print one `[wan] MXFP8 <expert> (nki): <dir>` line per expert — C4/C5.
3. The `--dual-expert` flag and `--quant` must forward together to the stage and DP workers — C5.
4. The CP2 run at 81 frames puts 16,380 rows per rank into the kernel (a multiple of 8) and at
   9 frames 2,340 (not): the 9-frame CP2 run is the on-device check of B7's padding — C7.
5. A spec quantized for tp4 loaded at tp2 must be refused by the transformer application (A3's
   check) with a message naming both tps — covered by phase A's test; C3 adds the Wan instance.
