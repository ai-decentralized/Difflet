The best value of the chosen metric for each model is in bold. “vs best” compares only the platforms you selected that ran the same workload (shape and guidance, plus the step count for end-to-end times and quality): times slower for speed, the gap in dB or SSIM for quality. “—” means not measured or nothing to compare with.
