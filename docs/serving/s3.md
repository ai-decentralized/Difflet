# S3 artifact storage for `difflet serve`

By default `difflet serve` returns generated PNGs inline as Base64 data URLs and
keeps completed videos on local disk behind the Videos content endpoint. This page
describes the optional private S3 mode, where generated bytes are uploaded to a
bucket and the response carries an expiring presigned URL instead.

## Enable

Create an environment file next to where you start the server:

```bash
cp .env.example .env
```

Set the bucket and region:

```dotenv
DIFFLET_S3_BUCKET=difflet
DIFFLET_S3_REGION=ap-southeast-4
DIFFLET_S3_PREFIX=difflet
```

Run the server from the directory containing `.env`. If the file exists, it is
loaded automatically without overriding variables already exported by the shell.
Do not commit `.env` or credentials.

## Credentials

Boto3 uses its standard credential provider chain. On EC2, attach an IAM role to
the instance instead of storing access keys in `.env`. The role needs
`s3:PutObject` and `s3:GetObject` on `arn:aws:s3:::<bucket>/<prefix>/*`.

## URL lifetime

Difflet always returns an S3 presigned URL whose access lifetime is controlled by
the server-owned `artifact_ttl_seconds` setting (currently 3600 seconds). Keep S3
Block Public Access enabled. A bucket lifecycle rule may delete expired objects
later; URL expiry and object deletion are independent.

## S3-compatible providers

For non-AWS providers (Cloudflare R2, MinIO, and similar), set
`DIFFLET_S3_ENDPOINT_URL` explicitly. AWS S3 does not need it; boto3 derives the
endpoint from `DIFFLET_S3_REGION`.

Providers that do not use the boto3 default credential chain may set
`DIFFLET_S3_ACCESS_KEY_ID` and `DIFFLET_S3_SECRET_ACCESS_KEY`;
`DIFFLET_S3_SESSION_TOKEN` is optional for temporary credentials. The access key
and secret key must either both be present or both be absent.

Difflet uses SigV4 and virtual-hosted addressing for AWS presigned URLs.
Providers that require path-style URLs may set
`DIFFLET_S3_ADDRESSING_STYLE=path`.

## All variables

| Variable | Required | Purpose |
|---|---|---|
| `DIFFLET_S3_BUCKET` | yes, to enable S3 | Target bucket |
| `DIFFLET_S3_REGION` | yes, to enable S3 | Bucket region |
| `DIFFLET_S3_PREFIX` | no | Key prefix inside the bucket (default `difflet`) |
| `DIFFLET_S3_ENDPOINT_URL` | non-AWS only | Custom endpoint |
| `DIFFLET_S3_ACCESS_KEY_ID` / `DIFFLET_S3_SECRET_ACCESS_KEY` | non-AWS only | Explicit credentials, both or neither |
| `DIFFLET_S3_SESSION_TOKEN` | no | Temporary-credential token |
| `DIFFLET_S3_ADDRESSING_STYLE` | no | `path` for providers that need path-style URLs |
| `DIFFLET_S3_CLIENT_TIMEOUT` | no | boto3 client timeout in seconds (default 60) |
